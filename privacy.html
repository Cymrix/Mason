Privacy Policy for Mason 2D Level Editor

Effective Date: August 28, 2026

Mason 2D Level Editor ("Mason", "we", "our", or "us") respects your privacy. This Privacy Policy explains how your information is handled when you use the Mason web application and its optional Google Drive and Microsoft OneDrive integration features.

1. Overview & Data Storage

Mason is primarily a client-side web application. All project data, biome configurations, custom tilemaps, and sprite sheets are stored locally in your browser's localStorage / IndexedDB unless you explicitly connect an optional cloud storage provider.

Google User Data Policy Compliance: Mason does not store, harvest, sell, or share your personal data or Google Drive files on any third-party external server. All token exchanges and file transactions occur directly between your browser and official Google API endpoints.

2. Information Collected & Used

a. Local Data

Your level designs, map assets, editor preferences, and session state are stored directly in your browser. No level files are transmitted to us.

b. Google Drive API Usage

If you choose to log in with Google Drive to back up or sync your level files, Mason requests access to the https://www.googleapis.com/auth/drive.file scope. This restricted permission allows Mason to:

  • Create, edit, open, and save only the level files (.mason, .map, .json) created by or explicitly opened with Mason inside your Google Drive.
  • Mason cannot read, modify, or delete any other files or folders in your Google Drive.
  • OAuth tokens are stored securely in your browser's private local storage session and are used exclusively to authenticate direct client-to-Google API calls.

c. Microsoft OneDrive API Usage

If you connect Microsoft OneDrive, Mason uses the Microsoft Graph API with the delegated Files.ReadWrite.AppFolder scope to save level files inside a dedicated MasonMapEditor folder in your OneDrive.

3. Third-Party Services

Mason connects directly to official APIs provided by:

  • Google OAuth 2.0 & Google Drive API: Google Privacy Policy
  • Microsoft Graph API & OneDrive: Microsoft Privacy Statement

4. Data Retention and Deletion

You have complete control over your data:

  • You can disconnect Google Drive or Microsoft OneDrive at any time using the Cloud Storage & Sync menu inside Mason. Disconnecting immediately removes access tokens from your browser storage.
  • You can revoke Mason's access to your Google Account at any time via Google Account Security Settings.
  • Deleting a file inside Mason's cloud manager removes that file from your Google Drive or OneDrive.

5. Security

All communication with Google Drive and Microsoft OneDrive APIs occurs exclusively over encrypted HTTPS connections using industry-standard OAuth 2.0 protocol authentication.

6. Changes to This Privacy Policy

We may update this Privacy Policy periodically to reflect improvements in our app or changes in cloud platform requirements. Updates will be published on this page with a revised effective date.

7. Contact Us

If you have any questions about this Privacy Policy or Mason 2D Level Editor, please contact the developer at maranojesse@gmail.com.
