üìñ Cloud Setup & Instructions
Google Drive Storage
  1. Active Service Toggle: Use the top slider to switch the active cloud service to Google Drive.
  2. Sign In: Click Sign In to connect your Google account in the secure Google sign-in window.
  3. Target Folder: Projects save into your configured full path (default: /Palette Spray Studio). You can enter any custom path (e.g. /Art/Projects) and click Apply, or navigate subfolders using Browse Folders.
  4. Save & Load: Enter a file name and click Save to Cloud to store your complete artwork project. Click Load on any file in the list to open it directly into the canvas.
Microsoft OneDrive Storage
  1. Active Service Toggle: Use the top slider to switch the active cloud service to OneDrive.
  2. Sign In: Click Sign In to connect your Microsoft account.
  3. Target Folder: Projects save into your configured full path (default: /Palette Spray Studio). You can enter any custom path or browse directories directly.
  4. Save & Load: Save or load .pssproj projects seamlessly across your devices.
Automatic Cloud Backups & Sync
  • Automatic Cloud Backups: Check Automatic Cloud Backups to periodically upload project snapshots directly to your target folder on the active cloud service.
  • Active Cloud Association: Once a project is saved to or loaded from the cloud, pressing Ctrl+S or clicking Save updates the cloud file directly.
  • Data Security: Authentication tokens reside only in your local browser session; data transfers travel directly to official Google Drive and Microsoft Graph APIs.
